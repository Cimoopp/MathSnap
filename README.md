# MathSnap

Офлайн-решатель математики для Android: фотографируешь пример — приложение само
распознаёт цифры и знаки своей нейросетью и показывает пошаговое решение.

Всё работает без интернета: и распознавание, и решение считаются на телефоне.

## Как это устроено

1. Камера снимает пример.
2. Препроцессинг: серый цвет, контраст, бинаризация, нарезка на отдельные символы.
3. Своя CNN (TensorFlow Lite) узнаёт каждый символ: 0–9, + − = ( ) x y . / √ ^ l g → всего 23 класса.
4. Строка собирается в формулу, дроби и степени восстанавливаются по геометрии записи.
5. SymPy решает: дроби, степени, корни, логарифмы, уравнения.
6. Экран решения: что распознано → ответ → шаги по правилам.
7. История решённых примеров сохраняется на телефоне.

## Структура

```
MathSnap/
├── ocr/
│   ├── labels.py        # список классов — общий контракт модели и приложения
│   ├── model.py         # своя CNN
│   └── recognize.py     # (следующий шаг) препроцессинг и сборка строки
├── solver/
│   └── solve.py         # (следующий шаг) SymPy + пошаговые решения
├── train/
│   ├── train.py         # обучение и экспорт в .tflite
│   └── out/             # отчёты и метрики
├── data/
│   ├── download_data.py # загрузка датасета рукописных символов
│   ├── hasy/            # датасет HASYv2
│   └── handwritten/     # свои фото по классам
├── assets/model.tflite  # веса ИИ внутри APK
└── main.py              # (следующий шаг) Kivy: камера, решение, история
```

## Обучение модели

Локально:

```bash
pip install "tensorflow-cpu==2.15.1" pillow numpy
python data/download_data.py --out data/hasy
python train/train.py --epochs 30
```

В облаке: **Actions → Train OCR model → Run workflow**. Модель обучится и сама
закоммитится в `assets/model.tflite`, отчёт с точностью ляжет в артефакты.

Данные: HASYv2 — реальные рукописные символы (https://zenodo.org/records/259444),
плюс любые свои фото, которые положишь в `data/handwritten/<класс>/`.
Имена папок — ровно как в `ocr/labels.py`: `7`, `+`, `sqrt`, `x`, `l` и т. д.

## Вес

| Часть | Сколько |
|:---|---:|
| Своя модель (после квантования) | 0,3–0,5 МБ |
| Kivy + Python | 40–60 МБ |
| SymPy + mpmath | 15–25 МБ |
| numpy + Pillow | 10–15 МБ |
| Иконки, шрифты, ресурсы | 3–5 МБ |
| **Итого APK** | **80–130 МБ** |

Тяжёлые OpenCV и Tesseract намеренно не используются: для рукописных формул они
почти бесполезны, а APK раздувают на 60–100 МБ.
